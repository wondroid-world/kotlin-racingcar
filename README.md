- [ ] 주어진 횟수가 있다.
- [ ] 주어진 횟수는 0이거나 양수이다.
- [X] 자동차 이름이 있다.
- [X] 자동차 이름은 5글자를 초과할수 없다.
- [X] 자동차 이름은 ""일 수 없다.
- [X] 자동차 이름은 1글자 이상이다.
- [X] 자동차가 있다.
- [X] 자동차는 이름을 가진다.
- [ ] 이동 거리가 있다.
- [ ] 이동 거리는 0이거나 양수이다.
- [ ] 자동차는 이동 거리를 가진다.
- [ ] 자동차는 전진한다.
- [ ] 자동차는 멈출 수 있다.
- [ ] 랜덤 숫자가 4이상이면 전진한다.
- [ ] 자동차 여러대가 있다.
- [ ] 자동차의 이름은 쉼표(,)를 기준으로 구분한다.
- [ ] 우승자를 알려준다.
