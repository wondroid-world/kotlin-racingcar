# kotlin-racingcar

초간단 자동차 경주 게임을 구현한다.

- [x] 자동차 이름의 길이는 1자에서 5자 사이이다.
- [x] 자동차 초기 위치는 0이다.
- [x] 자동차가 전진하면, 위치가 1 증가한다.
- [x] 전진 조건에 만족을 하면, 자동차가 위치는 1 증가한다.
- [x] 자동차를 생성할 때, 이름이 있어야한다.
- [x] n대의 자동차 중 많이 전진한 자동차가 우승자이다.
- [ ] 우승자는 한 명이상일 수 있다.
- [ ] 주어진 횟수만큼 게임을 진행한다.
- [ ] 0에서 9 사이에서 무작위 값을 구할 수 있다.
- [ ] 무작위 값이 4이상이면 전진한다. 
- [ ] 자동차 이름은 쉼표(,)를 기준으로 구분한다.
- [ ] 사용자는 몇 대의 자동차로 몇 번의 이동을 할 것인지를 입력할 수 있다.
